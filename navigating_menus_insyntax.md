# Navigating Menus in Syntax

### Operations menu

- Enter the number for selection and will be indicated at the bottom left of the screen.
- Press a number again for a corresponding selection in the submenu
- some menus maybe hidden or accessed only in a submenu
- Pressing `F10` key in Order Processing menu and pressing shows addtional order processing options


### Navigating in a Screen

- `Tab` allows the user to move from one field to the next 
- `Shift` + `Tab` allows the user to move to the previous field.
- `Ctrl` + `Enter` is the field exit key to exit a field
- A mouse can also be used to place a cursor in the desired field.  

### Function Keys

- Syntax requires the use of 24 keys
- To access functions key greated than `F12` us the `shift` key with the correspondng function key.
- To signoff in syntax type `99` after exitng all current menus using `F3`
