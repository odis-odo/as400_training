# Mapping the Keyboard

<br>

- Click the remap icon at the top of the screen for the keyboard screen mapping
- Click the category drop down menu in the key assignment tab
- Press `Search for Key` under host functions to see current key mapping.
- Select a function that you wish to change and press `Unassign Key` to clear the current key.
- Then use the `Assign a Key` to reassign a new key for the function.
- The `Reset All` key reset all keys to default settings.
